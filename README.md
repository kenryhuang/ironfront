# IRONFRONT · 铁锋 0.6

单机全球领土策略游戏：积攒守军、扩张陆地、持续进攻、运兵船航行和海外登陆。国家与战斗参数为原创简化模型；世界物理轮廓来自 Natural Earth，不表示历史或现实国界。

## 运行

需要 Node.js 20 或更新版本。Three.js 0.180.0 的 ES 模块已随源码本地打包，运行无需 CDN 或安装依赖。

```sh
npm run dev
```

打开 http://127.0.0.1:5173 。`PORT` 可指定端口，服务仅监听本机。

```sh
npm test
npm run build
```

`dist/` 为静态部署产物，需要 HTTP 服务打开，不能直接双击 HTML。所有地图数据随项目打包，游戏无需外部服务。

## 立体沙盘

默认使用 2.5D 沙盘：世界坐标中的山脊、沟谷、岩面与积雪网格，明亮日光、地形与设施投影，以及城市、工厂、兵营、要塞等多部件立体模型。地形与设施共用同一个场景变换，平移和缩放时维持相同地块位置。放大后能观察屋顶、门窗、烟囱和圆形塔楼；建设过程中模型随工程进度升起。右上角“2.5D 沙盘 / 俯视地图”可切换视角。地形按对齐的世界网格细分，最多约22万三角面，不为百万游戏地块分别创建对象。

地貌包含缓起伏平原、圆缓丘陵、盆地低地与周边坡面，以及11条美术示意河流。河流绘制与河床下切使用同一条平滑路径，包含河岸过渡；水面保留蓝色。河网与地貌均为美术生成，不是测绘数据，目前不改变地块陆地连通或过河规则。

领土使用独立的 RGBA 纹理贴在同一个立体地表上：岩石、积雪之后染色，再共同接受地形光照与阴影，因此我方和敌方颜色均沿山峰、坡面、丘陵和谷地显示。占领、失地和选中边界会实时更新；河水不被领土颜色覆盖。

立体模式使用地表射线拾取，缩放保持光标所在地图位置，建设、选择与实时圈画继续使用原有地块。国名、兵力、作战标记使用独立高清标注层，避免被山体或建筑遮住。无 WebGL2 或图形上下文失效时回退俯视地图。美术高程按主要地理山系生成，不是实测高程，也不会改变现有战斗地形规则。

## 全球作战

1. 点击无主陆地或岛屿部署，或使用位于欧洲海岸附近的推荐位置。
2. 点击“扩张无主土地”，持续占领接壤空地。土地与城市决定人口上限，人口随时间增长；正规军由兵营训练，也可紧急强征。
3. 选择邻国并调整出兵比例，然后“发动进攻”；重复下令为增援，双击地图可快速进攻。
4. 点击“自定义进攻”，按住鼠标自由圈画，松开自动闭合。不必选择国家，输入具体出兵人数，确认后部队仅在圈内可达的所有非己方陆地推进；圈外及不接壤的区域不会被攻占。圈画期间战役继续运行，选区随战场实时更新，取消不扣兵，完成后余兵自动归队。
5. 跨海时点击“选择登陆海岸”，再点击非己方的沿海陆地。确认预览航线后“派遣运兵船”。船队由己方最近的可达海岸出发，直接扣除对应守军，不需要研发、港口、建筑或金币。
6. 船队沿真实水路航行；抵达无主海岸先支付扩张消耗，抵达敌岸先进行登陆战。余部从滩头连续向内陆推进，不会跳到其他大陆的边境。
7. 右侧新增“作战事件”，集中显示所有我方进攻与敌方来袭，展示剩余兵力、攻占数量、双方损失、自定义区域进度和海运航程。“前线部队”和“海上运输”保留详细部队状态。点击作战事件栏的停止按钮，终止对应任务并返还全部剩余兵力（已发生战损不返还），运输撤回目前直接归队，不模拟返程。

地图上金色为我方，红色为攻击我方的敌军，灰色为其他国家行动。地面箭头显示进攻兵力与目标全国守军，相关战斗显示损耗；运输船显示载兵数和剩余航程。为控制全球视图的信息量，同时最多显示 10 条与玩家无关的地面行动，玩家相关行动全部显示。前线面板进一步区分攻方损失与守方损失。

拖动平移、滚轮缩放（75%～3200%）、⌖ 重置视角；空格暂停或继续，Esc 取消海岸选择或自定义进攻。顶部支持 1× / 2× / 4×，重开清空本局。手机点击“态势 / 前线”查看部队和船队。

## 设施与征兵

选择左侧设施，再点击己方空地放置；设施至少间隔2地理单位，Esc取消选址。施工和生产随战役时间运行，暂停与倍速都会影响计时。

| 设施 | 造价 / 工期 | 完工效果 |
| --- | --- | --- |
| 城市 | 2400 / 20秒 | 人口上限+5000、人口增长+12/秒 |
| 工厂 | 1800 / 15秒 | 占用200工人，消耗8资金/秒生产6装备/秒 |
| 兵营 | 1600 / 15秒 | 每批100人+100装备、10秒训练100正规军 |
| 要塞 | 1600 / 15秒 | 附近5地理单位内，敌军攻占消耗乘2.4；不叠加 |

工厂停产立即释放工人。兵营可选择“训练正规军”或“整编强征军”，整编仅使用留守强征军，同样消耗装备和时间。停产或切换训练模式退回本批预留人员和装备。资金、人力或装备不足时自动等待。强征输入人数即可立即1:1将可用人力转为兵力，不消耗装备，战斗效能40%。城市不直接生成士兵。

设施被占领时停止生产，原国工人与训练资源归还原国，设施和施工进度移交新国；占领者可手动恢复。战斗死亡减少人口，撤回部队保持正规军/强征军构成。当前保留原跨海功能，不要求港口。

## 当前规则

| 项目 | 规则 |
| --- | --- |
| 人口上限 | 10,000 + 领土面积 × 65 + 已完成城市 × 5,000 |
| 人口增长 | 每秒 `8 + 领土面积 × 0.03 + 已完成城市 × 12`，达到上限停止 |
| 人口分配 | 可用人力 + 工人 + 训练中 + 留守 + 出征 + 海运，强征军是兵力的子集 |
| 装备和资金 | 开局400装备、10,000资金；基础收入每秒 `24 + 领土面积 × 0.14` |
| 无主扩张 | 每格基础消耗 `7 × 地块面积 × 地形系数`（当前地块面积 1/16） |
| 战斗效能 | 正规军100%，强征军40%；出兵按比例混编，战损按比例扣除 |
| 敌方守军损失 | 每格 `d = 全国留守兵力 / 领土数量 × 0.8` |
| 进攻消耗 | `(7 × 地块面积 + d × 防守方平均效能 × 1.15) × 地形系数 × 要塞系数 ÷ 攻方平均效能` |
| 地形系数 | 平原 1、丘陵 1.3、山地 1.8 |
| 地面推进 | 每秒尝试 `16 × (6 + sqrt(出征兵力) × 0.13)` 个细地块，按面积保持原节奏 |
| 海上速度 | 每秒 9.6 个细水路网格，按实际航程保持原速度 |
| 船队数量 | 每国最多 6 支同时航行的船队，单船队载兵总量由出兵比例决定 |
| 地图 | 1440×720（1,036,800 个地块），七大洲和主要岛屿，海上寻路支持跨太平洋左右边界 |
| 胜利 | 消灭其他所有国家，不要求占领无主岛屿 |

出征与海上部队不参与本土防守；普通进攻会先抵消同对手的相向进攻，自定义进攻仅抵消进入圈定区域的相向部队。普通地面增援合并，独立登陆点保持独立军队。失地后人口超过上限时人口停止增长，不立即删除现有人口或部队。目标消失或不再接壤时存活地面部队自动归队。船队抵达时依据当时海岸所有者结算；已经属于己方则卸载归队。失去全部领土的国家立即灭亡，陆军与海运部队清除。

AI 与玩家使用相同规则，保留守军，扩张、选择较弱邻国、反攻，并能向海外空地和敌国派船。AI也会建设城市、工厂、兵营和要塞，并在兵力不足时强征。当前没有研发。

0.3 将可玩网格密度提高到 0.2 的 4 倍，采用 Natural Earth 1:50m 详细海岸线、浅蓝海洋和明亮地形。细地块以面积归一，兵力容量、增长、攻占消耗及航速不会直接因为像素加密而翻倍。渲染改为像素缓冲区批量上传、平滑缩放和高分屏画布，避免高密度地图逐格反复绘制造成卡顿。

0.4 将海岸显示与模拟网格分离。原始地理轮廓保留小数精度，通过 Path2D 在当前缩放和高分屏分辨率下绘制，地形、领土颜色都由同一矢量陆地蒙版裁切，不再放大栅格海岸或用插值把台阶模糊掉。视角未变时复用地理蒙版和海岸描边，只更新国家占领层。沿海点击会在相邻模拟地块中校正；被采样遗漏的小岛补回至少一个陆地格，以支持部署和登陆。

0.5 将国家占领边界改为缓存的平滑矢量轮廓，缩放时直接重绘曲线，并增加自由圈画进攻区域、精确兵力分配与独立任务增援。普通点击进攻保持原有规则。

## 代码

- `src/facilities.js`：设施施工、人口、工厂、训练队列与强征。
- `src/troops.js`：混编效能、转移、战损和归队。
- `src/engine.js`：国家、经济、地面战斗、运输和登陆生命周期。
- `src/naval.js`：只经过水面的最短航路及船队位置插值。
- `src/map.js`、`src/world-land.js`：世界轮廓的扫描线栅格化及初始势力。
- `src/ai.js`：地面与跨海决策。
- `src/renderer.js`：地图、实时军队数字、箭头、航线和船只。
- `src/territory.js`：领土轮廓提取、内洞及平滑曲线。
- `src/attack-plan.js`：自由圈画选区和圈内可达区域校验。
- `src/coastline.js`：保留原始精度的海岸矢量路径。
- `src/battle-events.js`：实时作战事件与停止操作。
- `src/main.js`：交互和指挥面板，保留按钮节点避免定时刷新中断焦点。
- `tests/`：核心规则、海运、全球地理和多种子长局一致性。

小型旧规则测试保留原有即时城市/工事接口；全球战役使用施工、人口和装备生产规则。地图数据来源与公共领域声明见 THIRD_PARTY_NOTICES.md。

## 尚未实现

尚无存档、多人联网、真实二战国界与完整兵种、研发、海上拦截、舰队战斗和补给线。关闭或刷新页面会丢失本局。全国守军模型不代表具体前线的局部驻军，图上已明确标注。

地图细化：横纵地块密度各提高 2 倍，单格边长减半、面积变为原来的 1/4，实际可玩网格增至 1,036,800 格。地块面积归一规则继续保持经济与攻占消耗、海运尺度。

## 研发内容草案

两条六阶段先展开后汇合的研发树，各21项，共42节点：战术军事为历史装备与军工技术，科学研究延伸至1958年的核能与卫星项目。包含历史资料、前置、设施条件及费用时长。见 [完整节点目录](docs/research/README.md)、[可搜索预览](docs/research/research-browser.html) 和 [结构化数据](docs/research/research-catalog.json)。研发已接入战役：打开左侧国家研发科技树，满足前置与已完工设施条件后一次付费开始；切换保留进度，暂停或失去设施时等待，完成后应用本版即时加成。每个节点的当前效果见 [即时效果表](docs/research/live-effects.md)。飞机、军舰、核能、卫星等独立系统仍为后续许可。结构核查：`node scripts/validate-research.mjs`。

设施升级：卡片显示升级所需科技、资金和工期，完工后提升等级。城市提高人口上限与增长，工厂按级别增加工人、产量与维护费，兵营按级别缩短训练，研究所每级提供5%科研速度；港口每级提供20/秒贸易收入，须沿海建设。机场、雷达站、铁路节点提供对应研发设施门槛。
