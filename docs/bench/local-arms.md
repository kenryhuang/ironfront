# 局部装甲炮击模拟

入口：`/docs/bench/combined-arms.html`。使用原游戏欧洲地图、Game战斗与Renderer地形；不读写正式战役。

当前出兵规则：默认步兵/装甲命令覆盖全部接敌边界；自定义区域覆盖圈内全部前线。从所有已建成、归属己方且陆路相通的兵营中，按到目标前线的陆路距离选择最近一座。各路从同一兵营出发并在前线展开，共享本次投入兵力；接敌后按前线宽度分摊推进速度，避免前线越长消耗越剧烈。绘制抽样小队和坦克，实际每段前线均参与模拟。炮击命中按各路的实际位置计算。缺少可用兵营时拒绝命令且不扣兵。

海运同样从距离登船海岸最近的连通兵营调兵。步兵先沿己方陆路走到岸边，运输船等待登船，随后驶向目标海岸。行军期间撤回返还兵力；陆路被切断则中止并返还。船体已增加收窄船底、斜船艏、驾驶舱侧窗、桅杆和船尾舵。页面标题标注“全线进攻 · 最近兵营出兵 · 立体运兵船”便于辨认版本。

基础步兵开局可用，具有钢盔、背包、步枪和行走姿态。步兵以1.5格/秒连续推进，占领半径0.9格，没有装甲减伤；双方步兵和海运登陆部队使用同一位置驱动模拟及模型。最多32名代表士兵按身体部件实例化绘制，人数增加不增加士兵绘制调用。实际兵力以任务栏为准。

运兵船最多6艘，使用既有海运扣兵、海上寻路、撤回及登陆规则。局部模拟船速上限2.4格/秒，便于观察；有船艏、舱室、甲板人员、尾流与登陆坡道。手动派船入口已移除；圈画不接壤的可达沿海区域会自动海运，登陆后仍受圈选边界约束。抵岸后转换成步兵持续推进。“运兵船近景”“步兵近景”定位当前模型。暂停冻结步态、航行和尾流，静止时不持续刷新地形缓存。

T08/T11预先解锁。常规进攻与配属12辆坦克的进攻可作对比，支持自由圈画和撤回。炮兵展开后齐射3发，范围伤害和20秒压制作用于实际守军、前线部队、设施。生产使用局部演示配额，尚未接入正式战役兵种生产菜单。

指定一次炮击区域后，每8秒自动齐射3发；停止炮击取消后续轮次，当前齐射继续。弹药耗尽时保留目标，手动付费补充后继续；目标中心被我方占领则自动停火。转移中停止炮击，火炮沿连通己方陆路连续移动，到达后展开3秒才能射击；无法跨海或穿越敌方领土瞬移。运动中的轮组、炮口后坐和弹道共用原渲染循环。

立体表现：固定池最多6辆代表坦克、3门火炮、3枚炮弹和3段弹道。真实剩余编制以任务栏为准。几何/材质共享，轮组实例化，没有额外动画循环、动态光源或动态阴影贴图；使用原有地形场景与深度遮挡。火炮沿目标转向，逐门闪光和后坐，炮弹从模型炮口沿三维抛物线飞行。暂停冻结动画；待命时复用地形缓存。重置释放原模型资源。

装甲行军由模拟层管理，模型直接使用同一位置，独立于渲染帧率。到前线后保持连续移动，携带剩余移动距离跨过路径节点；没有逐格等待或攻击进度条。车头周围半径1.35格的连通区域随车扫过归属我方，战损在同一更新中处理而不冻结车辆。路线沿陆地与授权圈选区域延伸，避免每占一格都重走寻路。界面显示行军/持续推进，装甲不再绘制与车辆脱节的远程交战箭头。装甲或炮弹运动期间允许约60次/秒绘制，静止地图继续使用原缓存节奏。炮击依据部队实际位置命中，敌军发起反攻不会隔空抵消后方行军部队。

推进参考：[OpenFront AttackExecution](https://github.com/openfrontio/OpenFrontIO/blob/main/packages/engine/src/execution/AttackExecution.ts) 中连续更新边境的处理方式；本项目的车辆扫掠占领为独立实现，没有移植其代码。

“部队近景”查看待命编队；进攻期间定位当前坦克位置。“速度”可切到×0.25慢放。“回到战区”返回局部全景。

验证：`node --test tests/local-arms.test.js tests/local-arms-models.test.js`，覆盖真实领土推进、压制到期、撤回、装甲战损、炮弹模型起终点、连续移动、暂停、对象池和资源释放；`npm run build`。
