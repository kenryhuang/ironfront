# 空军双战场局部模拟

入口：`/docs/bench/air-operations.html`。使用原游戏的欧洲地图、立体地形、设施、地面全线推进和海运。双方配额与研发预解锁，仅供本页；没有更改正式战役。

## 试玩顺序

1. 点击地图右上角飞机按钮进入空中战场，或点击右侧“演示：巡逻抵御轰炸”。蓝方战斗机起飞，4秒后敌方轰炸机来袭，覆盖区内自动拦截。
2. 点击“敌方战斗机巡逻”观察争夺空域和自动空战。蓝、红范围分别为双方制空，重叠黄色区域为争夺区。没有战斗机时无人控制；地面国土不决定制空权。
3. 选择侦察机、航空侦察，在敌方地面点击或自由圈画。附近设施被发现，失去视野后只保留灰色旧情报。机场始终公开。
4. 选择战略轰炸机、设施轰炸，指定情报栏中的敌方设施；派出后可选择战斗机、护航，指定其编队。飞机飞抵后投弹，1.4秒后才结算伤亡、设施损坏和18秒压制。
5. 地面视图可发动步兵/装甲全线进攻，与前线支援轰炸配合。领土仍由地面部队实际推进占领。

## 其他任务

- 攻击机可圈选海域打击现有运兵船；右侧按钮触发敌军从兵营赴海岸出航。移动舰船使用提前量瞄准，海军其他舰种尚未接入。
- 运输机选择己方陆地为空运补员；选择敌后空降则消耗真实守军，幸存载员落地作战，建立落点后在周围5地块内推进。空运补员目前回到国家守军池，不建立独立驻军系统。
- 飞机每批生产4架，受机场等级、研究、资金、装备和容量约束。本页预解锁研究，容量为每级机场32架。
- 持续任务返航后花费每架45资金、3装备，整备6秒。缺资源或机场受损时暂停。整备只修复幸存飞机，击落的飞机必须重造。
- 召回停止后续任务，返航才归还飞机与载员。已投出的炸弹仍会落地。机场失效时空中飞机寻找其他己方机场；无基地则盘旋，航时用尽损失。机场失守时正在整备的飞机损失。
- 固定敌方要塞兼做防空阵地，可被轰炸压制或摧毁。本页尚未提供单独建设防空炮按钮。

## 性能与规则

模拟和显示分离。空战每0.25秒更新目标与伤害，飞机每帧平滑移动，模型池上限36个代表飞机（不代表实际人数），另复用8个坠机位置；云层使用单平面着色，无体积光或新动态灯光。切换视图和圈选不暂停游戏，隐藏页暂停推进。所有数值均为游戏平衡参数。

转弯倾斜随实际转向变化，转直后平滑回正；重型飞机倾斜幅度更小，交战时有轻微爬升与俯仰。开火显示移动的短曳光弹与短促枪口闪光，最多保留32组射击效果。单架飞机损失时生成独立坠机，翻滚下坠4.2秒并留下逐渐消散的烟迹，残骸不再参与战斗或制空计算。烟雾共用一张缓存贴图，每架坠机最多16个烟点；所有动画使用游戏时间，暂停时冻结。
