# 正式战役空军

正式入口 `/` 使用 `CampaignGame`、`AirOperations` 和 `AirRenderer`。独立试玩仍保留，但正式战役不调用 `seed`，没有预送飞机、机场或航空研发。

| 研发 | 开放内容 | 出动设施 |
| --- | --- | --- |
| T07 航空制造与无线电探测 | 战斗机、攻击机、侦察机；巡逻、护航、前线支援、海上打击、侦察 | 已完工Ⅰ级机场 |
| T14 航空动力与机体工程 | 战术轰炸机、运输机；设施轰炸、空运补员、敌后空降 | 已完工Ⅰ级机场；同时允许升级Ⅱ级 |
| T21 远洋海空与远程打击 | B-29战略轰炸机 | 已完工Ⅱ级机场 |

左侧“航空指挥”选择机型，生产每批4架，支付实际资金与装备。机场每级提供32机位，生产队列、库存和出动飞机均占用机位。机场施工、受压制、严重受损或核污染时暂停生产；可取消并返还未用资金、装备。

选择任务后，点击地图或按住鼠标自由圈画下令。运输每架最多300人，载员来自留守军队并计入总人口；阵亡真实扣除载员。护航选择已起飞的己方非战斗机编队。右侧航空任务显示机数、状态、航时、载员，并可定位或召回。持续任务返航后支付整备费再出动，损失飞机不会免费补回。

地图右上角进入空中战场：白雾覆盖地面，只保留机场与模糊国土。战斗机的实际覆盖范围决定制空权，敌我战斗机重叠为空域争夺；自动交战和拦截，不提供手动拦截指令。返回地面后仍能看到飞行模型与轰炸。未侦察的敌方非机场设施在模型和鼠标提示中均隐藏，旧情报保留最后已知位置。国土与兵力保持公开。

AI每6秒决策航空任务，逐项支付前置科研、设施和生产费用。前期发展T07航空线，后续发展T14；每国最多3支AI出动编队，全场仍受24支编队上限约束。没有免费空军或定时刷机。

复用试玩飞机几何、按转向倾斜、曳光弹和冒烟坠落；36个在役代表模型及8个坠机池，32组射击效果。正式固定计算步长使用只读插值平滑显示，不改变命中或制空判定。没有空军且处于地面时不创建空军模型池。地面兵种、核弹投送仍使用原有机制。

验证：`npm test`、`npm run build`。`tests/campaign-air.test.js`覆盖正式战役资金、生产、机场失效、运输人口守恒、空战及灭国清理；`tests/air-ai.test.js`覆盖敌方付费发展与出动；`tests/air-motion.test.js`覆盖固定计算步长下的显示插值。
