# 正式战役：合成兵种与自动海运

正式入口 `/` 使用 `CampaignGame` 与 `CombinedArmsRenderer`。局部试验页仍使用独立 `LocalArmsGame` 预设；两者共享推进、炮击、运输和模型模块，不共享对局状态。

- 每国初始领地获得一座停训兵营。基础兵力可立即从该兵营出发；玩家可开启训练，继续消耗人力、装备补充正规军。
- 步兵与装甲沿整条接敌边界分路推进。自定义进攻限定在圈内。选择最近的、已建成且己方陆路连通的兵营作为出发点；未到负责前线前不占地。增派部队创建独立行军任务，最多同时六支陆军。
- T08 开放坦克生产：运作中的工厂消耗1,800资金、120装备，12秒完成12辆。每支装甲进攻配属12辆；撤回返还幸存坦克。工厂被占、停产、施工、压制或核污染会暂停装配；取消返还未用部分资源。
- T11 开放炮兵：1,800资金、120装备组建一支三门代表火炮的炮兵队，含18发炮弹。选择己方阵地，展开3秒后可持续炮击；每8秒三发，支持停止、补弹和沿己方陆路转移。炮击会误伤友军，削弱区域守军并压制20秒。补弹花费300资金、20装备，耗时5秒。
- 没有手动派遣运兵船按钮。自定义选区接壤时使用陆路；完全不接壤且包含可达海岸时自动预览海运，确认后按指定兵力扣除。部队从兵营走到海岸登船，沿真实水路航行，抵岸后仅在原选区推进。装甲选区可以随船运输坦克。没有可达海岸则拒绝且不扣兵。跨越多个不连通陆块的圈选只处理当前登陆点连通的区域，预览会提示已排除的不可达地块。
- 步兵、坦克、炮兵、船体及炮弹共用地形场景与模拟时间；暂停冻结动画。固定数量的代表模型表达实际编制，人数以任务栏为准。士兵按部件实例化，船只及装甲使用固定池，优先绘制屏幕内和玩家部队；不新增动画循环、动态光源或动态阴影。

验证：`npm test`、`npm run build`。核心接入覆盖在 `tests/campaign-arms.test.js`、`tests/auto-landing.test.js`；原有装甲连续推进、全线部署、模型缓存、炮击、海运和研发测试继续保留。
